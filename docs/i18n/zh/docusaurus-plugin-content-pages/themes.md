# 主题

ReactPress 主题驱动**访客站**。它们是消费 CMS 内容的 Next.js 应用，提供 SSR/ISR、SEO、sitemap 与 OG 标签——管理后台保持不变。

## 安装主题

1. 打开 **后台 → 外观 → 主题**
2. 浏览 npm 目录并安装官方主题
3. 激活主题 — `reactpress init` 也可自动激活 featured 主题

完整流程见 [外观与主题](/zh/docs/user-guide/appearance-themes)。
