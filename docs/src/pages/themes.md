# Themes

ReactPress themes power the **visitor-facing site**. They are Next.js apps that render CMS content with SSR/ISR, SEO, sitemap, and OG tags — while Admin stays the same.

## Install a theme

1. Open **Admin → Appearance → Themes**
2. Browse the npm catalog and install an official theme
3. Activate it — `reactpress init` can also auto-activate the featured theme

See [Appearance & themes](/docs/user-guide/appearance-themes) for the full Admin workflow.
